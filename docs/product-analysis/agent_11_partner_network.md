# Агент 11: Партнёрская сеть

## Хостинги

### Beget
- **Сайт**: [beget.com](https://beget.com), [beget.ru](https://beget.ru)
- **Клиентов**: Крупный российский хостинг-провайдер, работает с 2007 года
- **Услуги**: Виртуальный хостинг, VPS/VDS серверы, регистрация доменов, облачные услуги (CDN, S3-хранилища, DBaaS)
- **Точки интеграции**: API для автоматизации управления услугами, собственная панель управления
- **Affiliate**: Партнёрская программа доступна (точные условия требуют уточнения на сайте)

### Reg.ru (REG.RU)
- **Сайт**: [reg.ru](https://www.reg.ru), [reg.com](https://www.reg.com)
- **Клиентов**: Более 3.3 миллионов доменов, более 2.2 миллиона клиентов
- **Услуги**: Регистрация доменов, SSL сертификаты, веб-хостинг, VPS, выделенные серверы
- **Точки интеграции**: API для управления сервисами, интеграция с популярными CMS
- **Affiliate**: Партнёрская программа доступна, условия требуют уточнения на сайте
- **Особенности**: Крупнейший регистратор доменов в России

### Timeweb
- **Сайт**: [timeweb.ru](https://timeweb.ru)
- **Клиентов**: Более 400,000 сайтов, один из лидеров рынка с 2006 года
- **Услуги**: Виртуальный хостинг, VPS/VDS, выделенные серверы, облачные решения, конструктор сайтов (Craftum)
- **Точки интеграции**: API для разработчиков, Terraform provider для автоматизации инфраструктуры
- **Affiliate**: До **40%** комиссии за привлечение клиентов
  - 40% комиссия на платежи за хостинг
  - Фиксированные 1000 ₽ за SSL сертификаты
- **ЦОД**: Санкт-Петербург, Новосибирск, Польша, Казахстан, Нидерланды

### Nic.ru
- **Сайт**: [nic.ru](https://www.nic.ru)
- **Клиентов**: Один из крупнейших регистраторов доменов и хостинг-провайдеров РФ
- **Услуги**: Регистрация доменов, хостинг, VPS, SSL
- **Точки интеграции**: API для управления услугами
- **Affiliate**: Партнёрская программа доступна, условия требуют уточнения

### FirstVDS
- **Сайт**: [firstvds.ru](https://firstvds.ru)
- **Клиентов**: Популярный провайдер VPS/VDS услуг
- **Услуги**: VPS/VDS серверы, выделенные серверы
- **Точки интеграции**: API для управления серверами
- **Affiliate**: Партнёрская программа доступна, условия требуют уточнения

### Selectel
- **Сайт**: [selectel.ru](https://selectel.ru)
- **Клиентов**: Более 18,000 клиентов, включая крупные IT-компании, банки и государственные организации
- **Услуги**: VPS, выделенные серверы, облачное хранилище, CDN, IaaS
- **Точки интеграции**: Обширное API, infrastructure-as-code capabilities
- **Affiliate**: Партнёрская программа для бизнеса
- **ЦОД**: Собственная Tier III+ инфраструктура, SLA 99.95%-99.98%

### RU-VDS
- **Сайт**: [ruvds.com](https://ruvds.com)
- **Клиенты**: Бюджетный VDS провайдер
- **Услуги**: VPS/VDS с гибкой конфигурацией ресурсов
- **Точки интеграции**: API для управления сервисами
- **Affiliate**: Партнёрские возможности доступны

## CMS

### 1C-Bitrix / Bitrix24
- **Популярность в РФ**: ~1.6% глобального рынкаshare, доминирует в корпоративном сегменте РФ и СНГ
- **Статистика Marketplace**:
  - **15M+** пользователей Bitrix24 weltweit
  - **670+** приложений в маркетплейсе
  - **160+** разработчиков
  - **900K+** скачиваний приложений
  - **200+** API методов
- **Партнёрская сеть**: Более 8,000+ партнёрских компаний (по данным 2012, растёт на 20% ежегодно)
- **Точки интеграции**:
  - REST API с ~200 методами
  - PHP SDK (mesilov/bitrix24-php-sdk)
  - Python SDK (fast_bitrix24)
  - Три типа приложений: JS-приложения, сторонние hosted, внешние через API
- **Монетизация**: Freemium модель, мгновенный доступ к миллионам пользователей

### WordPress
- **Популярность в РФ**: 64.7% глобального рынкаshare, доминирует и в РФ
- **Пользователей в СНГ**: Более 726,000 клиентов
- **Точки интеграции**:
  - Плагинная архитектура (60,000+ плагинов)
  - REST API
  - WooCommerce для e-commerce
- **Популярные интеграции в РФ**:
  - JivoChat (чат)
  - Yoast SEO + Яндекс.Webmaster
  - YaySMTP (email)
  - Множество платежных шлюзов

### MODX
- **Популярность в РФ**: Активная русскоязычная сообщество, официальный сайт modx.ru
- **Точки интеграции**:
  - Мощная система расширений
  - API для создания кастомных решений
  - Поддержка multi-site
- **Особенности**: Open-source, гибкость для интеграций

### Joomla
- **Популярность в РФ**: 3.3% глобального рынкаshare, declining but still present
- **Точки интеграции**: Расширения, API

### Яндекс.Директ + CMS
- **Точки интеграции**: Плагины для популярных CMS с интеграцией рекламных инструментов Яндекс

## Облачные провайдеры

### Yandex Cloud
- **Сайт**: [cloud.yandex.ru](https://cloud.yandex.ru)
- **Доля рынка**: **47.4%** - лидер рынка облачных сервисов в России
- **Услуги**: Managed databases, Kubernetes, вычислительные мощности, хранилище, AI-сервисы (YandexGPT)
- **Точки интеграции**:
  - Обширное API
  - Terraform provider
  - SDK для различных языков программирования
- **Партнёрская программа**: Маркетплейс решений, партнёрская сеть
- **Особенности**: ~25% компаний при миграции в публичное облако выбирают Yandex Cloud

### Selectel Cloud
- **Сайт**: [selectel.ru](https://selectel.ru)
- **Доля рынка**: **17.5%** - второе место
- **Услуги**: Облачная инфраструктура, VPS, хранилище, CDN
- **Точки интеграции**:
  - OpenStack API
  - Terraform provider
  - Инфраструктура как код
- **Партнёрская программа**: Корпоративные партнёрства, реселлерская модель

### Cloud.ru (SberCloud)
- **Сайт**: [cloud.ru](https://cloud.ru)
- **Доля рынка**: **14.3%** - третье место
- **Услуги**: Облачные вычисления, хранилище, AI-сервисы
- **Точки интеграции**: API для разработчиков
- **Партнёрская программа**: Экосистема Сбера

### VK Cloud (бывший Mail.ru Cloud)
- **Сайт**: [vkcloud.ru](https://vkcloud.ru)
- **Партнёрская сеть**: **5,000+ партнёров** (интеграторы и реселлеры)
- **Услуги**: VK Workspace, облачная инфраструктура
- **Точки интеграции**:
  - API для быстрого provisionинга сервисов
  - Без начальных инвестиций
  - Техническая сертификация для партнёров
- **Особенности**: С ноября 2024 все операции с новыми клиентами идут через партнёрскую сеть
- **Рынок**: Корпоративные коммуникации растут на 13% в год, прогноз до 80 млрд к 2027

## Конструкторы сайтов

### Tilda (Тильда)
- **Сайт**: [tilda.cc](https://tilda.cc), [tilda.ru](https://tilda.ru)
- **Позиционирование**: Индустриальный стандарт в России
- **Точки интеграции**:
  - API для экспорта сайтов
  - Встроенные интеграции с CRM, email-маркетингом, платежными системами
  - Возможность добавления кастомных виджетов
- **Affiliate**: Подробности требуют уточнения на сайте

### Bazium (Базиум)
- **Рейтинг**: 97/100 - лучший в категории для SEO и продаж
- **Особенности**:
  - Виджеты "Увеличение продаж в 2 раза"
  - Блочный редактор как у Tilda
  - Интеграция с WhatsApp и Telegram
  - Поддержка MP4 видео
- **Ценообразование**:
  - Landing page: 3,480 руб/год
  - Website: 5,760 руб/год
  - E-commerce: 8,880 руб/год
- **Точки интеграции**: Мессенджеры, платежные системы

### Creatium (Креатиум)
- **Позиционирование**: No-code решения с внешними интеграциями
- **Точки интеграции**:
  - Airtable, Directual, Google Sheets
  - Zero-block функциональность
- **Особенности**: Серверы в Санкт-Петербурге, сингапурская версия для международного хостинга

### Taplink
- **Позиционирование**: Link-in-bio инструмент + мини-сайт конструктор
- **Основные сценарии**:
  - Био-ссылки для Instagram, TikTok, соцсетей
  - Мобильные микро-сайты
  - Витрины товаров и услуг
- **Особенности**:
  - AI page builder (создание страниц за 10 секунд)
  - 100+ шаблонов
  - 20+ контентных блоков
  - 0% комиссия на продажу цифровых товаров
  - 60+ платежных провайдеров
- **Точки интеграции**: Платёжные шлюзы, социальные сети

### Wix.ru
- **Позиционирование**: Глобальная платформа с русским интерфейсом
- **Пользователи**: 200+ миллионов по всему миру
- **Особенности**:
  - 1000+ отраслевых шаблонов
  - Drag-and-drop редактор
  - Запуск сайта за 1-3 дня
- **Ограничения в РФ**: Проблемы с приёмом платежей из-за санкций

### Другие платформы
- **uKit**: Бюджетный вариант для малого бизнеса
- **Craftum (Крафтум)**: Альтернатива Tilda
- **Flexby (Флексби)**: Вход в топ-4 российских конструкторов
- **T-Bank (Т-банк)**: Бесплатный вариант с ограниченными функциями

## Возможные точки интеграции

### 1. **Плагин/виджет для:**
- **Bitrix24 Marketplace**: Доступ к 15M+ пользователей, freemium монетизация
- **WordPress**: 726K+ клиентов в СНГ, WooCommerce интеграция
- **Tilda**: Встроенные виджеты и интеграции
- **Bazium/Creatium**: No-code платформы с возможностью интеграций
- **Taplink**: 60+ платежных провайдеров, link-in-bio сценарии

### 2. **Маркетплейс для:**
- **Yandex Cloud**: Публикация решений в маркетплейсе облачной инфраструктуры
- **VK Cloud**: Партнёрская сеть 5,000+ интеграторов
- **Selectel**: Enterprise-клиенты

### 3. **API Integration для:**
- **Хостинги (Timeweb, Beget, Reg.ru, Selectel)**: Автоматизация provisioning, white-label решения
- **Облачные провайдеры (Yandex Cloud, VK Cloud, Cloud.ru)**: Интеграция с облачной инфраструктурой
- **Bitrix24**: 200+ API методов для глубоких интеграций
- **Tilda**: API для экспорта и управления сайтами

### 4. **Партнёрские программы:**
- **Timeweb**: До 40% комиссии
- **Хостинги**: REVSHARE модель 5-40%
- **Bitrix24**: Freemium монетизация
- **VK Cloud**: Обязательная партнёрская модель для работы с клиентами

## Ключевые выводы

1. **Bitrix24** - самая привлекательная платформа для интеграции с огромной аудиторией (15M+ пользователей) и развитым маркетплейсом

2. **Yandex Cloud** - безусловный лидер среди облачных провайдеров в РФ (47.4% рынка)

3. **WordPress** остаётся доминирующей CMS и в РФ, несмотря на рост 1C-Bitrix

4. **Tilda** - стандарт де-факто среди конструкторов сайтов в России

5. **Тренд 2024-2025**: Рост локальных российских платформ из-за санкций и требований к суверенитету данных

6. **No-code платформы** (Creatium, Bazium) активно развиваются и предлагают интересные возможности для интеграций
