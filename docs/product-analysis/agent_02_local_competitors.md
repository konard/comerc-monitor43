# Агент 2: Локальные игроки РФ/СНГ

## Найденные сервисы

### UptimeRobot (глобальный, но популярен в РФ)
**Страна:** США (глобальный)
**Сайт:** https://uptimerobot.com/
**Функции:**
- HTTP(s), Ping, Port, Keyword мониторинг
- 5-минутные интервалы проверки на free-тарифе
- Email, SMS, голосовые уведомления
- Status pages (публичные страницы статуса)
- API для интеграции

**Цены:**
- Free: 50 мониторов, 5-минутные интервалы
- Pro: от $7-8/месяц (1-минутные интервалы)

**Gaps vs глобальные:**
- Широко используется российскими сайтами (pravmir.ru, infourok.ru, versia.ru, evotor.ru)
- Нет Russian-specific функций (СБП, локальные платежи)

---

### Uptime Kuma (Open Source, self-hosted)
**Страна:** Open Source (глобальный)
**Сайт:** https://github.com/louislam/uptime-kuma
**Функции:**
- Self-hosted решение (полный контроль данных)
- Мониторинг HTTP, TCP, ICMP, DNS, Docker, Steam, БД
- 20-секундные интервалы проверки
- 90+ интеграций уведомлений (Telegram, email, Slack)
- Красивый UI на Vue3
- Status pages

**Цены:**
- Бесплатный (Open Source)
- Требует собственного сервера для хостинга

**Gaps vs глобальные:**
- Идеален для data sovereignty (данные остаются в РФ)
- Популярен в российском tech-сообществе
- Требует технических навыков для настройки

---

### Zabbix (Enterprise)
**Страна:** Латвия (Zabbix SIA), популярен в РФ
**Сайт:** https://www.zabbix.com/
**Функции:**
- Масштабируемое enterprise решение
- Мониторинг инфраструктуры, сетей, приложений
- Высокая доступность, распределённый деплоймент
- Интеграция с Grafana для визуализации

**Цены:**
- Open Source (бесплатный)
- Enterprise поддержка: платно

**Gaps vs глобальные:**
- "Широкое применение и признание на российском рынке"
- Сложнее в настройке чем UptimeRobot
- Ориентирован на enterprise, не на SaaS

---

### Upptime (GitHub-based)
**Страна:** Open Source
**Сайт:** https://github.com/upptime/upptime
**Функции:**
- Полностью бесплатный (на базе GitHub Actions)
- Автоматическая генерация status pages
- Отслеживание response times и uptime
- Git-based история изменений

**Цены:**
- Бесплатный (в пределах лимитов GitHub)

**Gaps vs глобальные:**
- Нет российских серверов проверки
- Отлично для разработчиков и OSS проектов

### Ping-Admin (ping-admin.com)
**Страна:** Россия/СНГ (ориентирован на локальный рынок)
**Сайт:** https://ping-admin.com
**Функции:**
- Мониторинг серверов и веб-сайтов
- Мгновенные оповещения о сбоях
- Мониторинг корпоративной почты
- Фокус на предотвращении репутационного ущерба

**Цены:**
- Требуется уточнение на сайте

**Gaps vs глобальные:**
- Ориентирован на российский рынок
- Меньше функций чем у глобальных игроков

## Whitespace анализ

### Что делают локальные (чего нет у глобальных)
1. **Интеграция с российскими платежными системами** - ни один сервис не предлагает прямую интеграцию с СБП, ЮKassa, Сбербанк
2. **Локализованный сервер проверки** - большинство сервисов проверяют из-за рубежа, что даёт неточные результаты для RuNet
3. **Учёт "суверенного интернета"** - никто не тестирует доступность с учётом возможных отключений от глобального интернета
4. **Интеграция с российскими мессенджерами** - Telegram есть, но нет ВКонтакте, Telegram API может быть ограничен
5. **Цены в рублях** - большинство сервисов котируют в долларах/евро

### Что НЕ делают (чего нет у локальных, но есть у глобальных)
1. **Публичные status pages** - большинство локальных сервисов не имеют этой функции
2. **API-first подход** - у глобальных игроков богатые API
3. **Множественные локации проверки** - глобальные игроки имеют 60-100+ серверов по миру
4. **Интеграции с западными инструментами** - Slack, Discord, PagerDuty и т.д.
5. **SSL мониторинг** - отслеживание срока действия сертификатов

### Возможности для нового игрока
1. **SaaS-сервис мониторинга с серверами в РФ** - проверка изнутри RuNet для точных результатов
2. **Интеграция с СБП для оплаты** - уникальное преимущество для РФ рынка
3. **Status pages на русском** - готовые шаблоны для российских компаний
4. **Telegram-бот для уведомлений** - популярен в РФ/СНГ
5. **Мониторинг "белого списка"** - проверка доступности ключевых сервисов при ограничениях интернета
6. **Фильтрация false positives** - умное определение реальных проблем vs временных сбоев
7. **Прайсинг в рублях** - удобство для локальных клиентов
8. **Интеграция с российскими хостингами** - Timeweb, Beget, Reg.ru

## Выводы

1. **Рынок локальных SaaS-сервисов мониторинга практически пуст** - большинство российских пользователей либо используют глобальные решения (UptimeRobot), либо self-hosted (Uptime Kuma, Zabbix)

2. **Нет "убийцы" UptimeRobot на российском рынке** - пространство открыто для локального игрока

3. **Ключевое преимущество** - серверы проверки внутри РФ для точного тестирования доступности из RuNet

4. **Ниша** - SaaS-сервис для малого и среднего бизнеса с простым интерфейсом, российскими способами оплаты и серверами проверки в РФ/СНГ
