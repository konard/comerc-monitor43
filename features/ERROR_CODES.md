# ERROR_CODES.md — Канонический реестр кодов ошибок

Единый реестр всех error codes системы мониторинга.
Формат: `UPPERCASE_SNAKE_CASE`.

При создании новых сценариев:
1. Проверьте этот реестр на существующий код
2. Повторно используйте существующий код если подходит
3. Добавляйте новые коды только в этот файл

---

## Формат ответа об ошибке

```json
{
  "error": {
    "code": "ALERT_CHANNEL_NOT_FOUND",
    "message": "alert channel not found",
    "details": {},
    "request_id": "uuid"
  }
}
```

## Аутентификация и авторизация

| Код | Описание | HTTP |
|-----|----------|------|
| `AUTH_REQUIRED` | Требуется аутентификация | 401 |
| `AUTH_FAILED` | Ошибка аутентификации | 401 |
| `AUTH_TOKEN_EXPIRED` | Токен авторизации истёк | 401 |
| `FORBIDDEN` | Доступ запрещён | 403 |
| `PERMISSION_DENIED` | Недостаточно прав | 403 |
